Теги чатов: находите нужный чат по своим словам

Плагин для exteraLess, который позволяет подписать любой чат Telegram личными тегами и находить его по этим тегам в обычном поиске.

Скачать плагин Исходный код на GitHub

Зачем это нужно

Через год активного использования Telegram в списке легко оказывается несколько сотен чатов. Группа соседей по даче называется «СНТ Берёзка 2019», бухгалтер записан по имени и фамилии, а канал с полезными советами вы помните только по теме. Чтобы найти такой чат, приходится вспоминать точное название или долго листать список.

Папки помогают, но один чат часто относится сразу к нескольким темам, а папок мало. Теги решают эту задачу: вы подписываете чат так, как сами о нём думаете, и находите его по любому из этих слов.

Теги хранятся только на вашем телефоне. Плагин не выполняет сетевых запросов, ничего не отправляет и не читает содержимое сообщений. Другие участники чата тегов не видят.

Что умеет плагин

  • Теги для любого чата: личные переписки, боты, группы, каналы, секретные чаты, форумы.
  • Блок тегов в профиле прямо под кнопками «Чат», «Звук», «Звонок», «Подарок».
  • Удобный редактор с подсказками из тегов, которые вы уже использовали.
  • Поиск по тегам в общем поиске: компактные кнопки с найденными чатами над результатами.
  • Найденные чаты попадают и в обычную выдачу, стандартный поиск работает как прежде.
  • Отдельные теги для каждого аккаунта, если вы пользуетесь несколькими.

Как установить

  1. Скачайте файл chat_tags.plugin со страницы релиза.
  2. Отправьте его себе в «Избранное» и откройте в exteraLess, затем нажмите «Установить».
  3. В настройках доступа плагина выберите уровень «Доверенный» и разрешите hooks и messages.read. Они нужны, чтобы встроить блок в профиль и добавить результаты в поиск.
  4. Включите плагин и заново откройте любой профиль.

Обновление ставится так же, поверх старой версии. Удалять предыдущую не нужно, сохранённые теги останутся.

Как добавить теги

Откройте профиль чата и нажмите «＋ Добавить тег» под кнопками. Если теги уже есть, нажмите на их список. Второй путь, который работает всегда: профиль → ⋮ → Плагины → Добавить / изменить теги.

Правила записи

  • Один тег — одна строка. Запятая и точка с запятой тоже разделяют теги: вода, взносы — это два тега.
  • Внутри тега можно писать фразу: поставщик плитки — один тег.
  • Регистр, лишние пробелы и решётка в начале не важны: #Дача, дача и ДАЧА — один и тот же тег.
  • Буквы «ё» и «е» не различаются: отчёты найдётся по запросу отчеты.
  • Русские и английские слова — разные теги: работа не найдётся по запросу work.
  • До 64 тегов на чат и до 128 символов в одном теге.
  • Чтобы удалить тег, сотрите его строку. Пустой список удаляет все теги чата.

Как искать

Начните вводить запрос в общем поиске чатов. Над обычными результатами появятся кнопки с названиями чатов, у которых нашёлся подходящий тег. Нажатие на кнопку сразу открывает чат.

Чем точнее совпадение, тем выше чат в списке: сначала полное совпадение с тегом, затем теги, начинающиеся с запроса, затем остальные.

Идеи для тегов

  • По сферам жизни: работа, семья, дача, учёба, здоровье.
  • По роли человека: бухгалтер, сантехник, репетитор, поставщик плитки.
  • По проекту: ремонт кухни, переезд 2026, свадьба.
  • По пользе: рецепты, скидки, полезные боты, прочитать позже.

Где хранятся данные

Теги лежат в настройках плагина на телефоне, отдельно для каждого аккаунта (по его Telegram ID). Между устройствами они не синхронизируются. Если удалить плагин или очистить данные приложения, теги могут пропасть.
