# Теги чатов для exteraLess

Плагин для [exteraLess](https://github.com/exteraless/exteraless): личные теги для любых чатов и поиск чатов по этим тегам прямо в общем поиске.

**[Скачать последнюю версию](https://github.com/Ovolsan/Chat-tags/releases/latest)** · [Файл плагина (RAW)](https://raw.githubusercontent.com/Ovolsan/Chat-tags/main/chat_tags.plugin) · [Подробная заметка с примерами](https://ovolsan.github.io/Chat-tags/)

## Зачем это нужно

В Telegram быстро набираются сотни чатов, и вспомнить точное название группы, канала или контакта бывает трудно. Папки помогают разложить чаты, но один чат удобнее держать сразу в нескольких смысловых группах, а папок слишком мало и они видны всем устройствам.

Цель проекта: дать возможность подписать любой чат своими словами («работа», «дача», «поставщик плитки», «#рыбалка») и находить его по этим словам через обычный поиск. Теги хранятся только на телефоне, никуда не отправляются и видны только вам.

## Возможности

- **Теги для любого чата**: пользователи, боты, группы, каналы, секретные чаты. В темах форума теги относятся ко всему чату.
- **Блок тегов в профиле** под кнопками «Чат», «Звук», «Звонок», «Подарок». Если тегов нет, показана кнопка **«＋ Добавить тег»**; нажатие на список тегов открывает редактор.
- **Редактор тегов**: один тег на строку (подходят также запятые и точки с запятой). При вводе предлагаются уже использованные вами теги, чтобы не плодить варианты написания.
- **Поиск по тегам в общем поиске**: при вводе запроса над результатами появляются компактные кнопки с аватарками и названиями найденных чатов, до двух строк. Кнопка **«Показать все (N)»** раскрывает полный список вниз, **«Свернуть»** возвращает две строки. Кнопки прокручиваются вместе со списком и не закрывают результаты.
- **Настройки кнопок:** аватарки можно отключить, а длинные названия чатов — обрезать до 10, 15, 20 или 30 символов.
- **Обычный поиск не меняется**: плагин не добавляет чаты в стандартную выдачу, найденные по тегу чаты показаны только кнопками.
- **Гибкое совпадение**: регистр и лишние пробелы не важны, ищется подстрока или все слова запроса внутри одного тега.
- **Раздельно по аккаунтам**: у каждого аккаунта свой набор тегов.
- **Приватность**: плагин не выполняет сетевых запросов, не читает и не индексирует содержимое сообщений.

## Примеры

| Чат | Теги | Найдётся по запросам |
| --- | --- | --- |
| Группа «СНТ Берёзка» | `дача`, `соседи`, `вода` | `дач`, `сосед`, `вода` |
| Иван Петров | `работа`, `бухгалтерия`, `отчёты` | `бух`, `отчёт`, `работа` |
| Канал о рыбалке | `рыбалка`, `снасти` | `рыб`, `снасти` |
| Бот для доставки | `еда`, `доставка пиццы` | `пицц`, `доставка`, `пицц дост` |

Запрос из нескольких слов находит тег, в котором есть все эти слова в любом порядке: `пицц дост` найдёт тег `доставка пиццы`. Буквы «ё» и «е» не различаются, решётка в начале тега необязательна: `#дача` и `дача` — один тег.

## Установка

1. Скачайте `chat_tags.plugin` из [последнего релиза](https://github.com/Ovolsan/Chat-tags/releases/latest), перенесите на телефон и откройте файл в exteraLess, например из «Избранного». Новую версию можно открыть поверх старой: удалять предыдущую не нужно, теги сохранятся.
2. Установите плагин. В его настройках доступа выберите уровень **«Доверенный»** и предоставьте **`hooks`** и **`messages.read`**. Разрешение `ui` подразумевается клиентом. При отсутствии нужных прав плагин показывает причину на своём экране настроек. Плагин не меняет уровень доверия и разрешения самостоятельно.
3. Включите плагин и заново откройте профиль чата.
4. Нажмите **«＋ Добавить тег»** под кнопками профиля. Также редактор открывается через **профиль чата → ⋮ → Плагины → Добавить / изменить теги**; этот путь работает даже без встраивания в профиль. Введите теги и нажмите «Сохранить».

## Правила тегов

- Один тег — одна строка; также подходят запятые и точки с запятой. Пробелы внутри фразы сохраняются.
- Дубли удаляются, регистр и лишние пробелы на поиск не влияют.
- Русское и английское написание — разные теги, автоматического перевода нет.
- До 64 тегов на чат, до 128 символов в теге. В профиле видны две строки тегов, полный список доступен в редакторе.
- Чтобы удалить тег, удалите его строку; пустой список удаляет все теги чата.

## Хранение данных

Теги сохраняются в собственных настройках плагина на устройстве. Для каждого аккаунта используется его Telegram user ID, поэтому повторное использование слота аккаунта не смешивает данные. Между устройствами теги не синхронизируются. Удаление плагина или данных приложения может удалить сохранённые теги.

Подсказки скрываются при поиске внутри форума и при медиафильтрах; специальные экраны выбора адресата сохраняют свои правила. Если чат удалён из локальной базы и кэша, при нажатии на его кнопку выводится сообщение о недоступности.

## Технические детали

Плагин объявляет только `ui`, `messages.read`, `hooks`; не выполняет сетевые запросы и не отправляет сообщения. Интерфейс обновляется в UI-потоке. Аватарки в кнопках берутся из кэша клиента; если чата там нет, показываются его инициалы. При открытии подсказки публичный SDK запускает отдельную очередь `chat_tags_open`, в которой безопасно вызывать `getChatSync / getUserSync`.

Запуск не нагружает главный поток: поиск классов, регистрация хуков и загрузка встроенного DEX выполняются в фоновой очереди плагинов. Выгрузка во время запуска дожидается его окончания и отменяет регистрацию.

Частые операции выполняет встроенный Java-помощник ([`native/src/chat/tags/TagsBridge.java`](native/src/chat/tags/TagsBridge.java), Base64 DEX в `chat_tags.plugin`): высота и положение блока при каждом кадре прокрутки профиля, отступ списка поиска и сдвиг кнопок вслед за прокруткой списка. Python хранит и сопоставляет теги, создаёт элементы интерфейса и редактор. Если DEX не загрузился, те же функции выполняют Python-хуки; режим виден на экране настроек плагина.

| Точка интеграции | Назначение |
| --- | --- |
| `BasePlugin.get_setting / set_setting` | Хранение тегов без разрешения на чужие файлы или настройки |
| `BasePlugin.add_menu_item / PROFILE_ACTION_MENU` | Редактор тегов через меню профиля, независимо от хуков |
| `ProfileActivity.getActionsExtraHeight(boolean)` | Дополнительное место под кнопками, без двойного учёта высоты |
| `ProfileActivity.createView / updateActionsPosition` | Блок тегов под кнопками и их положение при прокрутке |
| `ProfileActivity.onResume / onFragmentDestroy` | Обновление и очистка элементов профиля |
| `SearchViewPager` | Две строки кнопок в свёрнутом виде, раскрытие всех совпадений, отступ над обычной выдачей, прокрутка кнопок вместе со списком |

Проверки на ПК: `python -m unittest discover -s tests` и `python tools/verify_source.py ПУТЬ_К_EXTERALESS`. Сборка Java-помощника: `native/build.ps1` (JDK 17 и R8; пути задаются переменными `CHAT_TAGS_JDK` и `CHAT_TAGS_R8`) — компиляция, проверки на JVM, DEX для API 26 и встраивание в плагин.
