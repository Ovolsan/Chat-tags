# Теги чатов для exteraLess

Устанавливаемый плагин: **`chat_tags.plugin`**, версия **20261009**, автор **Ovolsan**. Пересобирать APK не требуется. Откройте новую версию как обновление существующего плагина; удалять старую версию перед обновлением не нужно.

[Скачать плагин (RAW)](https://raw.githubusercontent.com/Ovolsan/Chat-tags/main/chat_tags.plugin).

Плагин добавляет блок «Теги» в профиль над кнопками «Чат», «Звук», «Покинуть». Можно присваивать личные теги пользователям, ботам, группам, каналам и секретным чатам. В профилях без кнопок блок располагается в нижней части заголовка. В темах форума теги относятся ко всему чату.

При вводе в общем поиске появляются **максимум две строки компактных кнопок с названиями чатов**. В каждой строке помещается несколько чатов, если позволяет ширина экрана. Тег в кнопках не повторяется; длинные названия сокращаются многоточием, нажатие открывает чат. Если совпадений больше, чем помещается в две строки, кнопка **«Показать все (N)»** раскрывает весь список. Раскрытый список прокручивается; кнопка **«Свернуть»** возвращает две строки. При изменении запроса список автоматически сворачивается. Все найденные по тегам чаты также добавляются в обычную выдачу поиска. Обычный поиск продолжает работать.

## Установка

1. Перенесите `chat_tags.plugin` на телефон и откройте файл в exteraLess, например из «Избранного».
2. Установите плагин. В его настройках доступа выберите уровень **«Доверенный»** и предоставьте **`hooks`** и **`messages.read`**. Разрешение `ui` подразумевается клиентом. Эти разрешения нужны для встраивания в существующие экраны и чтения локальных данных чатов.
3. Включите плагин и заново откройте профиль чата. Состояние подключения видно на экране настроек плагина.
4. Нажмите **«＋ Добавить теги»** над кнопками профиля. Также редактор открывается через **профиль чата → ⋮ → Плагины → Добавить / изменить теги**. Введите первый тег и нажмите «Сохранить».

При отсутствии требуемых прав плагин показывает причину в своём экране настроек. Редактор в меню профиля доступен независимо от встраивания блока и поиска; для блока над кнопками и поиска нужны указанные выше права. Плагин не меняет уровень доверия и разрешения самостоятельно.

В версии 1.0.1 исправлен запуск: версия 1.0.0 обращалась к внутреннему Java-классу `PluginServices`, который форк запрещает плагинам. Теперь используется публичный SDK `client_utils.run_on_queue`, а ошибка установки хуков не убирает возможность добавить первый тег через меню профиля.

В версии **20261009** снято ограничение в два чата для поисковых подсказок: ограничено число строк свёрнутого блока. Добавлены перенос названий по ширине, раскрытие всех совпадений и прокрутка. Автор: **Ovolsan**. Обновляйте плагин без удаления: его ID и формат сохранённых тегов сохранены.

## Пример из запроса

В профиле AltTG добавьте три тега:

```text
телеграм
telegram
альтернативные клиенты телеграм
```

Теперь `телеграм`, `telegram`, `альтернативные` или `клиенты телеграм` найдут этот чат, даже если этих слов нет в его названии. Для канала о рыбалке достаточно добавить `рыбалка`.

Один тег — одна строка; также подходят запятые и точки с запятой. Пробелы внутри фразы сохраняются, регистр и лишние пробелы не влияют на поиск. Дубли удаляются. Русское и английское написание — отдельные теги: автоматического перевода нет. Поиск сопоставляет подстроку либо все введённые слова внутри одного тега.

В редакторе предлагаются уже сохранённые теги текущего аккаунта, максимум два однострочных варианта. Для удаления тега удалите соответствующую строку; пустой список удаляет все теги этого чата. На один чат доступно до 64 тегов по 128 символов. В профиле показаны две строки тегов, полный список доступен в редакторе.

Теги сохраняются в собственных настройках плагина на устройстве. Для каждого аккаунта используется его Telegram user ID, поэтому повторное использование слота аккаунта не смешивает данные. Между устройствами теги не синхронизируются. Удаление плагина или данных приложения может удалить сохранённые теги. Содержимое сообщений не индексируется.

## Совместимость и устройство

Исходники изучены в [exteraless/exteraless](https://github.com/exteraless/exteraless), версия приложения **12.10.6**, commit [`00c14f4`](https://github.com/exteraless/exteraless/tree/00c14f4c26e2cee39b2e966887f2edccd8de8893).

| Точка интеграции | Назначение |
| --- | --- |
| `BasePlugin.get_setting / set_setting` | Хранение тегов без разрешения на чужие файлы или настройки |
| `BasePlugin.add_menu_item / PROFILE_ACTION_MENU` | Добавление первого тега через меню профиля, независимо от хуков |
| `ProfileActivity.getActionsExtraHeight(boolean)` | Дополнительное место над кнопками, без двойного учёта высоты |
| `ProfileActivity.createView / updateActionsPosition` | Блок тегов и его положение при прокрутке |
| `ProfileActivity.onResume / onFragmentDestroy` | Обновление и очистка элементов профиля |
| `MessagesStorage.localSearch` | Добавление результатов в стандартный поиск, загрузка из базы при пустом кэше |
| `SearchViewPager` | Две строки кнопок в свёрнутом виде, раскрытие всех совпадений, отступ для блока над обычной выдачей |

Поиск по тегам добавляется в общий поиск чатов. Подсказки скрываются при поиске внутри форума и при применении медиафильтров; специальные экраны выбора адресата сохраняют свои правила. Чат, удалённый из локальной базы и кэша, не добавляется в обычную выдачу. Если его сохранённая подсказка осталась, при нажатии выводится сообщение о недоступности.

Плагин объявляет только `ui`, `messages.read`, `hooks`; не выполняет сетевые запросы и не отправляет сообщения. Интерфейс обновляется в UI-потоке. При поиске используются `getChat / getUser` в очереди хранилища. При открытии подсказки публичный SDK запускает отдельную очередь `chat_tags_open`: в ней можно безопасно вызывать `getChatSync / getUserSync`, которые отправляют чтение в очередь хранилища. Эти блокирующие методы не вызываются из самой очереди хранилища или UI-потока.

## Проверки

```powershell
python -m unittest discover -s tests -v
python tools/verify_source.py PATH_TO_EXTERALESS
python -m py_compile chat_tags.plugin
```

Проверки на ПК покрывают нормализацию, поиск фраз, ограничения подсказок редактора, сохранение и повторное чтение, разделение аккаунтов, удаление тегов, конкурентные обращения, согласованность массивов выдачи, отсутствие дублей, загрузку из базы и секретные чаты. Добавлены проверки сохранения первого тега без блока профиля, открытия редактора через меню, доступности меню при отказе в хуках и запуска без внутренних классов движка. Поиск проверяется на размещение нескольких чатов в строке, доступность третьего результата после раскрытия, перенос длинных названий, изменение ширины, прокрутку большого списка и восстановление отступов. `verify_source.py` использует настоящий парсер метаданных форка, сверяет сигнатуры хуков с Java-кодом и проверяет отсутствие классов из списка `_JAVA_CLASS_DENIED`; путь к другому checkout можно передать аргументом.

**Новая раскладка версии 20261009 на Android ещё не проверена.** Хостовые тесты и проверка исходников не подтверждают отображение и работу Java-моста на телефоне. Перед повседневным использованием проверьте:

1. Блок тегов над кнопками в профилях группы, канала, пользователя и бота; прокрутку и раскрытие аватара.
2. Сохранение трёх тегов AltTG, перезапуск клиента и поиск по каждому тегу.
3. Две строки компактных кнопок в свёрнутом виде, раскрытие всех чатов с одинаковым тегом, открытие третьего чата нажатием, сворачивание и возврат в поиск.
4. Светлую и тёмную темы, поворот экрана и увеличенный системный шрифт.
5. Второй аккаунт, удаление тегов, выключение и повторное включение плагина.
